# جاسوس آنلاین 🕵️ (نسخه ۲)

بازی جاسوس با اتاق و کد ۵ رقمی، روی Firebase (پلن رایگان) و GitHub Pages. سرور جدا لازم نداره.

## چی اضافه شد
- **چت اتاق** (دکمه‌ی وسط پایین صفحه) + دکمه‌ی **سؤال رندوم**: یه نفر رو انتخاب می‌کنه و یه سؤال مربوط به دسته‌ی این دور ازش می‌پرسه. مثلاً «سؤال از محمد: تا حالا اونجا رفتی؟»
- **تعداد دور**: آخر بازی قهرمان و جدول امتیاز رو نشون می‌ده. «شروع بازی جدید» امتیازها رو صفر می‌کنه.
- **زمان دور** رو هم تایپ می‌کنی (۱ تا ۱۸۰ دقیقه).
- **آفلاین**: کنار اسم کسی که قطع شده، علامت آنتن خط‌خورده میاد.
- **صدا**: میکروفون (حرف زدن) و هدفون (شنیدن)، هر کدوم جدا روشن و خاموش می‌شه.
- **QR کد** زیر کد اتاق. اسکنش کنی مستقیم وارد اتاق می‌شی.
- **اضافه کردن کلمه** (میزبان): یه دسته انتخاب کن و کلمه بنویس. با ✕ هم پاک می‌شه.
- **کیک**: میزبان روی ✕ کنار اسم هر کس بزنه، اون آدم از اتاق می‌ره و دیگه نمی‌تونه برگرده.
- قابل نصب به‌عنوان اپ (PWA) + پروژه‌ی اندروید آماده.

## ⚠️ قدم اول: قوانین Firestore رو دوباره Publish کن
چت، صدا و کیک قانون جدید لازم دارن. توی Firebase Console → Firestore Database → **Rules**، کل محتوای `firestore.rules` رو جایگزین کن و **Publish** بزن. بدون این کار، چت و صدا کار نمی‌کنن.

## راه‌اندازی سایت
1. همه‌ی فایل‌ها رو بریز توی ریپو و push کن (`.nojekyll` و پوشه‌ی `.github` هم باشن).
2. GitHub → Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)`.
3. توی `firebase-config.js` آدرس `WEB_URL` رو چک کن. الان روی `https://soheilezz.github.io/spy-online` تنظیم شده. اگه یوزرنیم یا اسم ریپوت فرق داره، درستش کن. QR و لینک دعوت از همین آدرس ساخته می‌شن.
4. Firebase → Authentication → Anonymous باید روشن باشه، و دامنه‌ی `github.io` تو Authorized domains باشه.

## ساختن اپ اندروید (APK)
پوشه‌ی `android` یه اپ کامل اندرویدیه که سایت رو باز می‌کنه و اجازه‌ی میکروفون رو هم می‌گیره.

**راه آسون (بدون نصب هیچ برنامه‌ای):**
1. اگه آدرس سایتت فرق داره، توی `android/app/build.gradle` خط `SITE_URL` رو عوض کن.
2. push کن. GitHub خودش APK رو می‌سازه (تب **Actions** → «ساخت اپ اندروید»، حدود ۵ دقیقه).
3. فایل APK توی بخش **Releases** ریپو با لینک دانلود مستقیم میاد. برای ساخت دستی هم از Actions → Run workflow استفاده کن.

**راه دوم:** پوشه‌ی `android` رو توی Android Studio باز کن و Build → Build APK رو بزن.

**راه سوم:** آدرس سایت رو توی pwabuilder.com بده و نسخه‌ی اندروید رو بگیر (فایل‌های PWA آماده‌ان).

> کلید امضای اپ (`android/app/jasoos.jks`) توی ریپوئه تا هر نسخه‌ی جدید روی قبلی نصب بشه. اگه ریپو عمومیه و براش مهمه، بعداً ببرش توی GitHub Secrets.

## صدا
اتصال صدا مستقیم بین گوشی‌هاست (WebRTC) و فقط برای پیدا کردن هم از سرور STUN گوگل استفاده می‌شه. روی بیشتر وای‌فای‌ها جواب می‌ده. اگه روی اینترنت موبایل وصل نشد، یه سرور TURN (مثلاً پلن رایگان metered.ca) توی `ICE_SERVERS` در `firebase-config.js` اضافه کن.

## فایل‌ها
- `index.html`: ظاهر، چت و داک پایین صفحه
- `game.js`: قوانین بازی (دورها، کلمه‌ی اضافه، کیک)
- `net.js`: ارتباط با Firestore (اتاق، چت، حضور)
- `voice.js`: صدای زنده
- `qr.js`: سازنده‌ی QR کد (بدون کتابخونه‌ی بیرونی)
- `words.js`: کلمه‌ها و سؤال‌های رندوم، هر چی خواستی اضافه کن
- `firestore.rules`: قوانین امنیتی

## محدودیت‌ها
- میزبان باید اپ رو باز نگه داره. اگه بیشتر از حدود ۹۰ ثانیه بره، میزبانی به قدیمی‌ترین بازیکن آنلاین می‌رسه.
- پلن رایگان Firebase روزانه ۵۰ هزار خوندن و ۲۰ هزار نوشتن داره. برای یه جمع دوستانه کافیه (چت و صدا هم مصرفشون کمه).
