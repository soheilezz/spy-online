# جاسوس آنلاین 🕵️

بازی جاسوس با اتاق و کد ورود ۵ رقمی. هر کس با گوشی خودش، از هر جایی.
هیچ پکیج اضافه‌ای لازم نیست، فقط Node.js نسخه ۱۸ به بالا.

## اجرا روی کامپیوتر خودت
```
node server.js
```
بعد برو به `http://localhost:3000`
برای بازی با بقیه روی همون وای‌فای: `http://آی‌پی-کامپیوترت:3000`

## گذاشتن روی اینترنت (رایگان)
**Render.com**
1. این پوشه رو بریز توی یه ریپوی GitHub.
2. توی Render بزن New → Web Service و ریپو رو انتخاب کن.
3. Build Command رو خالی بذار، Start Command: `node server.js`
4. لینکی که می‌ده رو برای دوستات بفرست.

روی Railway، Fly.io یا هر سرور لینوکسی هم همین `node server.js` کافیه (پورت رو از متغیر `PORT` می‌خونه).

## چطوری بازی می‌شه
- یه نفر **اتاق می‌سازه** و کد یا لینک دعوت رو می‌فرسته.
- بقیه با کد وارد می‌شن. حداقل ۳ نفر لازمه.
- میزبان دسته‌ی کلمه، زمان و تعداد جاسوس رو انتخاب می‌کنه (از ۶ نفر به بالا می‌شه ۲ جاسوس گذاشت) و شروع رو می‌زنه.
- هر کس انگشتش رو روی کارت نگه می‌داره تا کلمه‌ش رو ببینه. جاسوس فقط دسته رو می‌دونه.
- سؤال بپرسین، بعد رأی مخفی بدین. اگه جاسوس گیر بیفته، یه حدس آخر داره.
- جاسوس هر وقت بخواد می‌تونه زودتر کلمه رو حدس بزنه.
- امتیاز: شهروند برنده ۱، جاسوس برنده ۲.

## نکته‌ها
- کلمه‌ها توی `words.js` هستن، هر چی خواستی اضافه کن.
- کلمه‌ی مخفی هیچ‌وقت به گوشی جاسوس فرستاده نمی‌شه، پس با inspect هم نمی‌شه تقلب کرد.
- اتاق‌ها توی حافظه‌ی سرور هستن و با ری‌استارت سرور پاک می‌شن.
