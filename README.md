# جاسوس آنلاین 🕵️ (نسخه Firebase)

بازی جاسوس با اتاق و کد ۵ رقمی. این نسخه **سرور Node ندارد**: همه‌چیز روی Firebase (پلن رایگان Spark، بدون کارت) و فقط با فایل‌های استاتیک کار می‌کند.

## فایل‌ها
- `index.html`: ظاهر و صفحه‌ها
- `game.js`: قوانین بازی (همون منطق server.js قبلی)
- `net.js`: ارتباط با Firestore
- `words.js`: کلمه‌ها، هر چی خواستی اضافه کن
- `firebase-config.js`: تنظیمات Firebase و `WEB_URL`
- `firestore.rules`: قوانین امنیتی Firestore

## راه‌اندازی
1. **قوانین:** توی Firebase Console → Firestore Database → تب **Rules**، محتوای `firestore.rules` رو جایگزین کن و **Publish** بزن.
2. **Authentication → Sign-in method → Anonymous** باید روشن باشه. توی Settings → Authorized domains هم `soheilezz.github.io` رو اضافه کن.
3. فایل‌ها رو توی ریپوی GitHub بریز و push کن (فایل‌های `server.js`، `package.json` و پوشه `public` قبلی دیگه لازم نیستن).
4. توی GitHub: Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)`. بعد از یکی دو دقیقه آدرس `https://soheilezz.github.io/spy-online/` فعاله.
5. همون آدرس رو توی `firebase-config.js` جلوی `WEB_URL` بنویس (برای لینک دعوت).

## چطوری کار می‌کنه
گوشی **میزبان** نقش سرور رو داره: درخواست بقیه رو اجرا می‌کنه و وضعیت بازی رو توی Firestore می‌نویسه. کلمه‌ی هر بازیکن توی سند جدا ذخیره می‌شه که فقط خودش می‌تونه بخونه، پس جاسوس کلمه رو توی دیتا نمی‌بینه.

## محدودیت‌ها
- میزبان باید اپ رو باز نگه داره. اگه بیشتر از حدود ۹۰ ثانیه بره بیرون، میزبانی خودکار به قدیمی‌ترین بازیکن آنلاین می‌رسه.
- میزبان اگه فنی باشه می‌تونه کلمه رو از دیتای خودش ببینه (چون منطق بازی روی گوشی اونه).
- پلن رایگان روزانه ۵۰ هزار خوندن و ۲۰ هزار نوشتن داره. برای یه گروه دوستانه کافیه.
- اتاق‌های قدیمی خودکار پاک نمی‌شن (حجمشون ناچیزه).
